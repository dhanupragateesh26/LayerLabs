LAYERLABS PROJECT TECH STACK & REPLICATION BLUEPRINT

1. ARCHITECTURAL OVERVIEW
--------------------------------------------------------------------------------
Architecture: Decoupled Full-Stack Web Application (SPA/SSR Client + REST API)
- Frontend: Modern React Server/Client application hosted on Vercel
- Backend: Standalone Express REST API hosted on Render
- Database & File Storage: MongoDB Atlas with GridFS for binary object storage
- Email Delivery: Transactional email notifications (Resend API / SMTP)


2. FRONTEND STACK
--------------------------------------------------------------------------------
- Framework: Next.js 16 (App Router)
- Library: React 19 / React DOM 19
- Language: TypeScript 5
- Styling: Tailwind CSS v4 (@tailwindcss/postcss) + PostCSS
- 3D Rendering: Three.js (three, @types/three, STLLoader, OrbitControls)

3. BACKEND STACK
--------------------------------------------------------------------------------
- Runtime: Node.js (>= 18.0.0, CommonJS module format)
- Framework: Express 5 (5.2.1)
- ODM: Mongoose (9.3.3)
- File Uploads / Streaming: Multer (in-memory buffer storage) -> MongoDB GridFSBucket
- Email Service: Resend SDK / Nodemailer
- Security & Middleware: CORS, Dotenv
- Dev Tooling: Nodemon (3.1.14)

Backend Dependencies (package.json):

4. DATABASE & STORAGE LAYER
--------------------------------------------------------------------------------
- Primary Database: MongoDB Atlas (M0/Shared cluster or dedicated)
- Large File Storage: MongoDB GridFS (GridFSBucket: 'stl_uploads')
  * Eliminates the need for external S3 buckets for files up to 50MB
  * Files streamed directly from memory into MongoDB chunks
  * Automated background cron job for file lifecycle management / auto-deletion


5. ENVIRONMENT CONFIGURATION
--------------------------------------------------------------------------------
Frontend (.env.local):
  NEXT_PUBLIC_API_URL=http://localhost:5000  # Local development
  # (Production points to Render URL, e.g. https://your-backend.onrender.com)

Backend (.env):
  PORT=5000
  NODE_ENV=development
  MONGODB_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/<database>?retryWrites=true&w=majority
  ALLOWED_ORIGINS=http://localhost:3000,https://your-frontend.vercel.app
  RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxx     # For email delivery via Resend
  EMAIL_USER=your-email@example.com          # Optional fallback SMTP
  EMAIL_PASS=your-app-password               # Optional fallback SMTP App Password


6. DEPLOYMENT & HOSTING INFRASTRUCTURE
--------------------------------------------------------------------------------
- Frontend Hosting: Vercel
  * Root Directory: frontend
  * Framework Preset: Next.js
  * Build Command: npm run build
  * Output: Standalone Next.js SSR/Static build
- Backend Hosting: Render (Web Service / Blueprint via render.yaml)
  * Root Directory: backend
  * Runtime: Node
  * Build Command: npm install
  * Start Command: node server.js
  * Health Check Path: /health
